# TEDxVardhaman 2026 Official Event Website

A sophisticated, responsive web application designed for **TEDxVardhaman**, organised by **Vardhaman College of Engineering**, scheduled for **December 2, 2026**.

## Design Philosophy & Color Palette
- **Editorial Text Palette**: Carefully structured hierarchy using **Beige** (`#F5EFEB`, `#EADBCE`, `#D4C3B3`), **White** (`#FFFFFF`, `#F9F8F6`), **Black** (`#0A0A0A`, `#1A1A1A`), and **Brown** (`#A88B73`, `#8C6D58`, `#5A4335`, `#382A21`).
- **Signature TEDx Atmosphere**: Cinematic dark stage motif (`#000000`, `#0D0D0D`, `#141414`), red dot stage styling, and signature TED red (`#EB0028`) accents.
- **Typography**: Single approved typeface **Manrope** (clean Swiss editorial aesthetic), no italics, sentence case, and balanced typography.
